# MQ Multiplication Worksheet (Next.js + TypeScript)

A small printable worksheet generator (MVP) — Calculation Corner.

Quick start:
1. Place your MQ logo at public/mq-logo.svg (or public/mq-logo.png).
2. Place your OriginalSurfer.ttf at public/fonts/OriginalSurfer.ttf (optional, for title font).
3. Install dependencies:
   npm install
4. Run dev server:
   npm run dev
5. Open http://localhost:3000, generate a worksheet, then Print / Save as PDF.

To deploy:
- Push this repo to GitHub and import it into Vercel (recommended).
- Or use the Vercel CLI: npm i -g vercel; vercel; vercel --prod

License & fonts:
- Only host fonts you are licensed to serve. Replace the placeholder font if you do not have rights to self-host.
